# Mobile Doctor Lucknow

Doorstep mobile repair booking website for Lucknow.

- Full project blueprint: docs/BRIEF.md
- Brand settings: config/site.config.js
- Hosting: Cloudflare Pages (static site)
- Backend: Supabase (database + edge functions)

## Folders
- config/   brand settings (single source of truth)
- assets/   css, js, images, vendored libraries
- admin/    admin panel (client only)
- brands/   generated static brand pages
- supabase/ database migrations and edge functions
- tools/    helper scripts
- docs/     documentation and handover guides
